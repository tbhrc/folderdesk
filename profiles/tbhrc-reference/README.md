## What the TBHRC reference demonstrates

A mature ARC estate may separate:

- organisation direction ownership;
- one canonical Skills home;
- root `AGENTS.md` Router with progressive Fast Links;
- conditional owner/source lookup when the Router cannot resolve ownership;
- optional Issues/PRs/evidence when continuity or review is useful;
- Research;
- business/domain owners;
- revenue/lead/recruitment systems;
- public websites;
- privileged runtime infrastructure;
- private files and specialist systems;
- derived memory;
- learning/course material.

Current TBHRC organisation routing lives in [`tbhrc/workspace/AGENTS.md`](https://github.com/tbhrc/workspace/blob/main/AGENTS.md). Reusable operating HOW lives in [`tbhrc/workspace/.folderdesk/skills/`](https://github.com/tbhrc/workspace/tree/main/.folderdesk/skills). `tbhrc/skills` is retired provenance/compatibility only.

Do not copy TBHRC's repository names, mission wording or specialist-system choices into another business unless they genuinely match that organisation. ARC reproduces the mechanism and ownership boundaries; each target organisation owns its own direction and live system choices.
